# Music Lab 优化日志

本文档记录课程实验项目的界面、交互与性能优化，方便课堂展示和后续维护。

## 2026-06-09：第一阶段 - 核心布局与播放器

### 移动端布局

- 将手机端纵向大导航改为紧凑四栏导航。
- 缩小手机端顶部品牌区和账户入口。
- 调整歌曲列表、搜索区、统计卡片和操作按钮尺寸。
- 修复固定播放器大面积遮挡页面内容的问题。

### 自定义播放器

- 使用隐藏的 HTML5 Audio 元素承担音频播放。
- 新增播放、暂停、上一首、下一首控制。
- 新增播放进度、拖动跳转和时间显示。
- 同步播放器、歌曲列表和当前歌曲状态。
- 删除正在播放的歌曲时同步重置播放器。

### 首页信息层级

- 首页调整为“精选歌曲、最近加入、全部歌曲”三层结构。
- 最近加入由五张卡片精简为四张。
- 移除重复的分类文本输入框。
- 搜索与重置操作合并为统一工具栏。

## 2026-06-10：第四阶段 - 请求性能与发布文档

### 收藏状态性能

优化前，登录用户每次加载歌曲列表时，会为每首歌曲分别请求一次收藏状态：

```text
1 次歌曲列表请求 + N 次收藏状态请求
```

优化后，统一通过收藏列表接口同步收藏状态：

```text
1 次歌曲列表请求 + 1 次收藏列表请求
```

歌曲数量增加时，请求数量不再线性增长。

### 播放器补全

- 增加桌面端音量滑杆。

- 手机端隐藏音量滑杆，避免挤压主要播放控制。
