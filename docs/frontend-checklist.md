# 前端检查流程

## 1. 启动服务

后端：

```bash
cd backend
npm run dev
```

前端：

```bash
cd frontend
npm run dev
```

浏览器打开：

```text
http://localhost:5173/
```

## 2. 页面基础检查

- 页面不白屏
- 左侧或顶部显示 `Music Lab`
- 有资料库、上传歌曲、我的上传、我的收藏导航
- 桌面端左侧导航栏延伸到整个视口高度
- 右上角是小型账户入口，不再显示醒目的右侧账号卡片
- 页面是深色背景
- 首页有精选歌曲卡片和封面速览
- 播放、收藏、删除、上一首、下一首尽量使用图形按钮
- 底部播放器显示当前歌曲信息
- 浏览器控制台没有明显报错

## 3. 注册和登录

注册一个测试账号，期望：

- 提示“注册成功”
- 右上角账户入口显示用户名首字母
- `localStorage` 中有 `music_token` 和 `music_user`
- 点击右上角账户入口可以进入账户页
- 账户页显示用户角色、收藏数、上传数、歌曲数

退出登录后再登录，期望：

- 提示“登录成功”
- 刷新页面仍保持登录状态

## 4. 歌曲列表

- 首页能显示歌曲封面、歌名、歌手、专辑、分类、播放次数
- 首页统计区能显示歌曲数、播放数、收藏数
- 点击播放图形按钮后歌曲能播放
- 点击爱心图形按钮后收藏状态能切换
- 点击歌曲名可以打开详情弹窗
- 详情弹窗显示上传者、音乐路径、封面路径
- 点击关闭可以退出弹窗

## 5. 搜索和分类

- 输入关键词后点击搜索，列表只显示匹配歌曲
- 点击“重置”清空搜索条件
- 点击“全部、流行、民谣、摇滚、电子、其他”分类按钮可以筛选歌曲

## 6. 播放器

- 点击“播放”后底部播放器开始播放
- 当前播放歌曲在列表中高亮
- 播放次数增加
- 点击“上一首”和“下一首”能切换歌曲
- 歌曲播放结束后，如果列表里有多首歌，会自动播放下一首

## 7. 上传歌曲

登录后进入上传歌曲页，填写：

```text
歌曲名称
歌手
专辑
分类
时长
音乐文件
封面图片
```

期望：

- 页面显示“上传工作台”和右侧实时预览
- 填写歌曲名、歌手后，预览区同步更新
- 可以点击分类胶囊快速选择分类
- 选择文件后显示文件名
- 选择封面后右侧封面预览同步更新
- 检查清单能显示歌曲名称、歌手、音乐文件、封面图片状态
- 未选择音乐文件时提交按钮不可用
- 点击提交后显示“上传中...”
- 上传成功后提示“上传歌曲成功”
- 自动回到首页并看到新歌曲

## 8. 我的上传

- 登录后点击“我的上传”
- 只能看到当前账号上传的歌曲
- 可以播放、收藏或删除自己的歌曲
- 没有上传歌曲时显示空状态

## 9. 收藏

- 点击“收藏”后按钮变为“已收藏”
- 进入“我的收藏”能看到该歌曲
- 在首页或详情弹窗里可以取消收藏
- 取消后“我的收藏”列表同步更新

## 10. 删除歌曲

上传者或管理员可以看到“删除”按钮，普通用户不能看到。

期望：

- 点击删除会弹出确认框
- 确认后提示“删除歌曲成功”
- 首页列表移除歌曲
- 我的收藏中也不再显示该歌曲

## 11. UI 显示检查

- 桌面端侧边栏不遮挡内容
- 底部播放器不遮挡歌曲列表末尾
- 手机端导航、歌曲操作按钮、播放器能自动换行
- 长歌名、长路径在详情弹窗中不会溢出
- 深色背景下文字对比度清晰
- 图形按钮悬停和禁用状态正常

## 12. 测试数据检查

如果数据库里没有歌曲，可以运行：

```bash
cd backend
npm run seed
```

期望：

- 终端显示“测试歌曲数据已生成”
- 可以用 `demo / 123456` 登录
- 首页出现 6 首测试歌曲
- 测试歌曲可以播放合成音频
- `backend/uploads/music` 和 `backend/uploads/covers` 生成测试文件

## 13. 构建检查

```bash
cd frontend
npm run build
```

期望出现：

```text
✓ built
```
