# 前端检查流程

## 1. 启动服务

后端：

```bash
cd backend
npm run dev
```

前端：

```bash
cd frontend
npm run dev
```

浏览器打开：

```text
http://localhost:5173/
```

## 2. 页面基础检查

- 页面不白屏
- 顶部显示“音乐网站”
- 有首页、上传歌曲、我的收藏导航
- 底部播放器显示当前歌曲信息
- 浏览器控制台没有明显报错

## 3. 注册和登录

注册一个测试账号，期望：

- 提示“注册成功”
- 顶部显示用户名和用户角色
- `localStorage` 中有 `music_token` 和 `music_user`

退出登录后再登录，期望：

- 提示“登录成功”
- 刷新页面仍保持登录状态

## 4. 歌曲列表

- 首页能显示歌曲封面、歌名、歌手、专辑、分类、播放次数
- 点击歌曲名可以打开详情弹窗
- 详情弹窗显示上传者、音乐路径、封面路径
- 点击关闭可以退出弹窗

## 5. 搜索和分类

- 输入关键词后点击搜索，列表只显示匹配歌曲
- 点击“重置”清空搜索条件
- 点击“全部、流行、民谣、摇滚、电子、其他”分类按钮可以筛选歌曲

## 6. 播放器

- 点击“播放”后底部播放器开始播放
- 当前播放歌曲在列表中高亮
- 播放次数增加
- 点击“上一首”和“下一首”能切换歌曲
- 歌曲播放结束后，如果列表里有多首歌，会自动播放下一首

## 7. 上传歌曲

登录后进入上传歌曲页，填写：

```text
歌曲名称
歌手
专辑
分类
时长
音乐文件
封面图片
```

期望：

- 选择文件后显示文件名
- 点击提交后显示“上传中...”
- 上传成功后提示“上传歌曲成功”
- 自动回到首页并看到新歌曲

## 8. 收藏

- 点击“收藏”后按钮变为“已收藏”
- 进入“我的收藏”能看到该歌曲
- 在首页或详情弹窗里可以取消收藏
- 取消后“我的收藏”列表同步更新

## 9. 删除歌曲

上传者或管理员可以看到“删除”按钮，普通用户不能看到。

期望：

- 点击删除会弹出确认框
- 确认后提示“删除歌曲成功”
- 首页列表移除歌曲
- 我的收藏中也不再显示该歌曲

## 10. 构建检查

```bash
cd frontend
npm run build
```

期望出现：

```text
✓ built
```
